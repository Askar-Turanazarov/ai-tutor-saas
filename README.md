# Ustoz AI — персональный AI-репетитор английского

SaaS-репетитор английского из Ташкента: чат с разбором ошибок, темы A1–C2, персональный план-квизы в стиле Duolingo, тренажёр произношения. Интерфейс на русском, узбекском и английском, светлая и тёмная темы.

## Запуск

```bash
npm install
cp .env.example .env      # затем впишите AUTH_SECRET и (по желанию) ключи AI
npm run setup             # создаёт SQLite-базу и демо-данные
npm run dev               # http://localhost:3000
```

Регистрация не обязательна: кнопка «Начать» сразу создаёт гостевой аккаунт (Free). Гость может позже зарегистрироваться в «Настройках» — прогресс сохранится.

## Демо-аккаунты

Почта и пароли задаются в `.env` (`SEED_*`):

| Роль  | Email               |
|-------|---------------------|
| Админ | `admin@ustoz.local` |
| Free  | `free@ustoz.local`  |
| Pro   | `pro@ustoz.local`   |

## Тарифы

- **Free** — уровни A1–A2, лимит минут в день (по умолчанию 15, сброс в полночь по Ташкенту), простой разбор ошибок.
- **Pro** — все уровни и темы, без лимита, подробный разбор (правило + примеры), произношение, персональный план с квизами.

Оплата пока не подключена: кнопка «Перейти на Pro» сохраняет заявку, она видна в админке. Тариф переключается в админке.

## AI

Ключи в `.env`: `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` — работает любой набор. Роутер сам находит актуальные модели, сначала пробует быстрые, медленные Pro-модели — в конце. При ошибке, перегрузке или таймауте он незаметно переходит к следующей модели. Если недоступны все, отвечает встроенный офлайн-репетитор, так что пользователь никогда не видит ошибку.

## Админка — `/admin`

- **Обзор** — статистика и заявки на Pro.
- **Пользователи** — тариф, уровень, сброс лимита, «войти как», удаление.
- **AI-модели** — цепочка фолбэка, паузы, тестовый запрос, журнал вызовов.
- **Темы** — какие темы доступны только в Pro.
- **Параметры** — лимит Free, офлайн-режим, порядок провайдеров.
